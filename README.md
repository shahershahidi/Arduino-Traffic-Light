# Arduino Traffic Light Controller 🚦

## Project Overview

This is my first Arduino project, built as part of my electrical engineering learning journey.

I built a working traffic light system using an Arduino UNO R3, three LEDs, resistors, and a breadboard. The Arduino controls the lights automatically using C++.

## Components Used

- Arduino UNO R3-compatible board
- Breadboard
- Red, yellow, and green LEDs
- Three 220-ohm resistors
- Jumper wires
- USB cable

## Software Used

- Visual Studio Code
- PlatformIO
- Arduino Framework
- C++

## How It Works

The traffic light follows this sequence:

1. Red light turns on for 5 seconds.
2. Green light turns on for 5 seconds.
3. Yellow light turns on for 2 seconds.
4. The sequence repeats automatically.

## Pin Connections

| Arduino Pin | LED |
|---|---|
| D8 | Green |
| D9 | Yellow |
| D10 | Red |
| GND | Common ground through resistors |
